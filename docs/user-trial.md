## 0.8 试用追加任务（尚未执行）

请两位未参与开发的开发者分别完成以下任务，记录实际耗时、报错原文、系统与工具链版本。不要把自动化脚本输出记作用户反馈。

1. 使用 `sqlite-callback` 模板，修改查询并在 MoonBit 回调中复制实际文本和 NULL 值。
2. 主动在回调中抛出错误，确认 C 返回后的错误传播，并说明资源如何关闭。
3. 开启和关闭 `trace_calls`，分别解释“作者声明关联”“C 入口次数”“断言通过”三个字段。
4. 保存旧头文件后修改一个状态返回签名，运行 `upgrade --against`，找到契约和测试影响；确认原绑定没有被改写。
5. 安装命令入口，在另一个工作目录执行验证，记录是否需要额外配置。
