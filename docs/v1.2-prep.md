# MoonBind 1.2 发布记录与后续事项

状态：GitHub/CLI 正式版 1.2.0，发布日期见 `release-version.json`。Mooncakes 0.12.0 尚待认证与发布；真实用户试用仍待执行。

## 已完成的发布准备

- 最新 MoonBit 兼容任务覆盖 Ubuntu、macOS、Windows，并运行核心测试、原生验证和 SQLite 生命周期回归。
- 使用 clang 对照整数表达式、宏展开、短路求值以及固定数组、联合体、尾部填充布局。
- 记录 SQLite、zlib、cJSON、Zstandard 头文件的非门禁耗时基线。
- 保留 1.0 公共 API 基线、版本映射检查、源码包哈希和发布记录。

## 发布后仍需跟进

- 在 CI 中核对固定和最新工具链三平台验收结果；CI 通过记录以 GitHub Actions 为准。
- 完成至少两名未参与实现者的独立试用，记录任务完成、阻塞点和数据核对结果；自动化测试不代替真实用户试用。
- 完成 Mooncakes 0.12.0 的认证、dry-run、发布与独立消费验证。当前不要把该版本写成可安装依赖。
- 性能数据只作为同一主机/工具链下的趋势基线；没有重复测量证据前不据此宣称性能提升。

## 1.1 延续的未完事项

`docs/user-trial-v11.md` 记录的 1.1 独立开发者试用仍待执行。Mooncakes 0.11.0 也未发布；GitHub 源码发布不能代替注册表发布。
