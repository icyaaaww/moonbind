# MoonBind 1.2 使用与验收

GitHub / CLI 正式版：**1.2.0**，发布版本与 Mooncakes 注册表版本分别记录于 `release-version.json`。Mooncakes `0.12.0` 尚待认证、dry-run 与发布；最新已验证发布仍为 `0.10.0`，对应产品 1.0，不能安装来替代 1.2。

## 安装

下载 GitHub Release 中的 `moonbind-1.2.0-source.zip`，先按 `SHA256SUMS` 校验，然后解压并执行：

```sh
moon update
python moonbind.py install --prefix ../moonbind-install
```

安装需要 Python 3.10+ 和 MoonBit。原生验证需要平台 C11 编译环境；Windows 使用 MSVC Build Tools 与 Windows SDK。详细工作流与边界见 [1.0 使用与交付指南](v1.0.md)。

## 1.2 维护内容

- 解析和布局回归加入 clang 差分样本，覆盖宏展开、整数条件、固定数组、联合体和记录尾部填充。
- 最新 MoonBit 工具链 CI 覆盖 Ubuntu、macOS、Windows，包含核心测试、原生启动和 SQLite 生命周期回归。
- 对 SQLite、zlib、cJSON、Zstandard 头文件记录非门禁耗时基线；这些数字用于同主机/同工具链趋势比较，不是跨机器性能保证。
- 保留 1.0 公共 API 兼容基线和版本映射检查。

## 验收命令

```sh
moon update
moon check --target wasm-gc
moon test --target wasm-gc
moon info
python scripts/check-api.py
moon fmt --check
python scripts/verify-parser-corpus.py
python -X utf8=0 scripts/verify-v12.py --native
python scripts/verify-sqlite-demo.py
python scripts/benchmark-headers.py
```

布局差分脚本 `bash scripts/verify-layout.sh` 需要 clang。性能脚本会在 `_build/performance-*` 写入带输入 SHA-256、工具链和每次测量耗时的摘要；不设置绝对时间门槛。

## 已知状态与支持边界

GitHub 源码 Release 不代表 Mooncakes 已发布；未完成注册表认证、dry-run、发布和独立消费验证前，不要使用 `moon add icyaaaww/moonbind@0.12.0`。独立开发者试用仍待执行；自动化验收不等于真实用户反馈。MoonBind 仍不是完整 C/C++ 编译器，绑定生成也不能推断 C 库的所有权、生命周期或线程安全语义。
